# QA: Accessibility (M5)

## Overview
Accessibility pass ensures all custom elements have ARIA attributes,
visible focus indicators, screen-reader labels, and keyboard navigation.

Prefs: `zen.a11y.announce-space-switch` (default true),
`zen.a11y.announce-archive` (default true),
`zen.a11y.visible-focus` (default true)

## Test Cases

### TC-A11Y-001: Visible focus indicator
**Steps:**
1. Set `zen.a11y.visible-focus` to `true`
2. Navigate with Tab key through command bar
**Expected:** Focused element has a visible 2px outline

### TC-A11Y-002: ARIA on command bar
**Steps:**
1. Open command bar (Cmd/Ctrl+K)
2. Inspect with accessibility tools
**Expected:** Panel has role="dialog", aria-modal="true", aria-label

### TC-A11Y-003: ARIA on easel
**Steps:**
1. Open an easel
2. Inspect with accessibility tools
**Expected:** Canvas has role="region", aria-label; title has role="textbox"

### TC-A11Y-004: Keyboard navigation
**Steps:**
1. Navigate entire UI with Tab/Shift+Tab only
**Expected:** All interactive elements are reachable

### TC-A11Y-005: Screen reader labels
**Steps:**
1. Use a screen reader (NVDA/VoiceOver)
2. Navigate to command bar and easel
**Expected:** Meaningful labels announced for all controls

### TC-A11Y-006: Reduced motion
**Steps:**
1. Enable `prefers-reduced-motion` in OS
2. Open/close command bar and switch spaces
**Expected:** Animations are disabled or instant

## Acceptance Criteria
- [ ] All custom elements have ARIA roles and labels
- [ ] Visible focus indicators on all interactive elements
- [ ] Full keyboard navigation
- [ ] Screen reader compatible
- [ ] Reduced motion respected
